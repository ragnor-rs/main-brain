# is to tell a defect in the system from a defect in the harness must not have its dependencies
# change underneath it. A floating pin here would make "retrieval got worse" a thing that can be
# caused by a driver release.
#

# `urllib` does — and a client library would be a dependency carried for convenience in the file
# whose point is that nothing moves.
